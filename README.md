# Hardik Akkera · Portfolio

Personal portfolio for SEO and performance marketing work: case studies, channel strategy and measurement setup.

A single static page (`index.html`) with no build step, hosted on GitHub Pages.

## Update the site

1. Open `index.html` in this repository and click the pencil icon (Edit), or upload a new version with **Add file → Upload files**.
2. Commit the change. GitHub Pages republishes automatically within a minute or two.
